# iLO 4 Remote - Open Source Mobile App (Android APK & iOS IPA)

A cross-platform mobile application to manage and monitor **HP Integrated Lights-Out 4 (iLO 4)** servers directly from your smartphone or tablet over Wi-Fi.

---

## 📱 Features

- **⚡ Instant Power Management**:
  - Hero power dial with live status glow.
  - Power ON (Wake server from standby).
  - Graceful OS Shutdown (ACPI).
  - Momentary Power Button press.
  - Force Power OFF (Instant cut with confirmation safety prompt).
  - Hard System Reboot / Reset.
  - Unit Identification (UID) Blue Beacon LED toggle.
- **📊 Real-time Hardware Telemetry**:
  - Host Server model, Serial Number, BIOS/ROM version, Overall Health.
  - Dual Processor information and core stats.
  - Total Memory (RAM in GiB).
  - Power Supply units, redundancy state, and live wattage.
- **🌡️ HPE Sea of Sensors™ & Cooling Fans**:
  - Live readings from all 46 Sea of Sensors temperature zones with color-coded warning bars.
  - All 8 redundant chassis fans with live speed percentages.
- **📜 Integrated Event Logs**:
  - Integrated Management Log (IML) and iLO Event Log (IEL) viewer with severity filter badges.
- **🔌 Full REST API Explorer**:
  - Mobile REST playground with endpoint search, method selection (`GET`, `POST`, `PATCH`, `DELETE`), request body editor, and formatted JSON inspector.
- **🔄 Dual Connection Modes**:
  - **Direct Hardware Mode**: Communicates directly from your phone over Wi-Fi to your iLO 4 controller (`https://<ilo-ip>/rest/v1`) without needing any intermediate PC or server running!
  - **Companion Gateway Mode**: Connects through the companion FastAPI gateway server if desired.

## 📥 How to Install

### 🤖 Android (Direct APK Installation)

1. Download the latest compiled APK:
   - Found locally at [`releases/ilo4-remote-v1.0.0.apk`](file:///Users/dibyamahakur/PycharmProjects/ilo_4_interactive/releases/ilo4-remote-v1.0.0.apk) or from GitHub Releases.
2. Transfer the `.apk` file to your Android phone (via USB, Google Drive, WhatsApp, or browser download).
3. Tap the `.apk` file to install.
   - If prompted, toggle **Allow from this source** (standard for sideloaded APKs).
4. Launch **iLO 4 Remote**, enter your iLO IP (`192.168.8.53`), and start managing your server!

---

### 🍏 iOS (Sideloadable IPA)

The iOS project is configured for easy sideloading:

#### Option A: Sideloading via AltStore / SideStore / Sideloadly
1. Download the unsigned `.ipa` generated by GitHub Actions (or built from Xcode).
2. Open **AltStore**, **SideStore**, or **Sideloadly** on your computer/phone.
3. Select the `ilo4-remote.ipa` and enter your Apple ID to sign and install it directly onto your iPhone or iPad.

#### Option B: Building via Xcode
1. Open the native Xcode workspace:
   ```bash
   open mobile/ios/App/App.xcworkspace
   ```
2. Select your connected iPhone/iPad or Simulator as the target.
3. Select your Personal Team under **Signing & Capabilities**.
4. Click **Run** (Cmd + R) to install onto your device.

## 🛠️ Building From Source

### Prerequisites
- Node.js 18+ & npm
- JDK 17 (Eclipse Adoptium Temurin or OpenJDK)
- Android SDK (API 33+)

### Build Steps

1. Install dependencies:
   ```bash
   cd mobile
   npm install
   ```
2. Sync web assets into native projects:
   ```bash
   npx cap sync
   ```
3. Build the Android APK:
   ```bash
   cd android
   ./gradlew assembleDebug
   ```
   The output APK will be generated at:
   `android/app/build/outputs/apk/debug/app-debug.apk`

## 🚀 GitHub Actions Automated Releases

The repository includes a complete CI/CD workflow at [`.github/workflows/build-and-release.yml`](file:///Users/dibyamahakur/PycharmProjects/ilo_4_interactive/.github/workflows/build-and-release.yml).

Every time you push a git tag (e.g. `v1.0.0`), GitHub Actions automatically:
1. Compiles the Android APK.
2. Compiles the iOS IPA.
3. Creates a new GitHub Release with both the `.apk` and `.ipa` attached for instant public download!
